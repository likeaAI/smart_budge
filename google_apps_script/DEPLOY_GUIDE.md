# 💰 구글 시트 + 앱스크립트(GAS) 3분 배포 가이드

서버 호스팅 비용 0원! 구글 시트를 클라우드 DB로 사용하고, 스마트폰과 PC 어디서나 접속할 수 있는 **스마트 머니 허브** 배포 방법입니다.

---

### 🚀 배포 순서 (3단계)

#### 1단계: 구글 스프레드시트 만들기
1. [구글 스프레드시트](https://sheets.new)에 접속하여 새 시트를 생성합니다.
2. 제목을 `스마트 가계부 DB` 등으로 지정합니다.

---

#### 2단계: 앱 스크립트(Apps Script) 열기
1. 상단 메뉴에서 **[확장 프로그램] ➔ [Apps Script]**를 클릭합니다.
2. 기존 `Code.gs`의 내용을 모두 지우고, [Code.gs](./Code.gs) 파일의 내용을 전체 복사하여 붙여넣습니다.
3. 좌측 파일 목록에서 **[+] ➔ [HTML]**을 누르고 이름을 `Index`로 지정합니다.
4. 새로 생긴 `Index.html`에 [Index.html](./Index.html) 파일의 내용을 전체 복사하여 붙여넣습니다.
5. 상단의 **💾 저장(디스크 아이콘)** 버튼을 클릭합니다.

---

#### 3단계: 웹 앱(Web App)으로 배포하여 나만의 URL 받기
1. 우측 상단의 파란색 **[배포] ➔ [새 배포]** 버튼을 클릭합니다.
2. 왼쪽 톱니바퀴 아이콘을 눌러 **[웹 앱]**을 선택합니다.
3. 설정을 다음과 같이 지정합니다:
   - **설명**: `스마트 머니 허브 1.0`
   - **다음 사용자로 실행**: `나 (My account)`
   - **액세스 권한이 있는 사용자**: `모든 사용자 (Anyone)` 또는 `나만 (Only myself)`
4. **[배포]** 버튼을 클릭하고, 첫 실행 시 나타나는 권한 승인 창에서 **[고급] ➔ [이동(안전하지 않음)] ➔ [허용]**을 누릅니다.
5. 생성된 **웹 앱 URL**을 복사합니다!

---

### 📱 스마트폰 홈 화면에 앱처럼 추가하기
- 스마트폰 브라우저(사파리, 크롬 등)에서 복사한 **웹 앱 URL**을 엽니다.
- 브라우저 메뉴에서 **[홈 화면에 추가]**를 누르면 스마트폰 앱처럼 언제든 1초 만에 켜서 지출을 입력하고, 구글 시트와 카드값을 대조할 수 있습니다!
