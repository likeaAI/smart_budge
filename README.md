# 💰 스마트 가계부 (Smart Budget)

복잡한 텔레그램/SMS 자동화 대신, **사용자가 직접 웹에서 쉽고 직관적으로 기록하고 소비 습관을 인지·개선**할 수 있도록 설계된 웹 기반 스마트 가계부입니다.

---

## ✨ 핵심 기능

1. **📱 직관적이고 수려한 웹 UI**
   - **반응형 디자인**: 모바일 및 데스크톱 환경 모두에 최적화
   - **다크 모드 / 라이트 모드**: 사용자의 눈 피로도를 줄여주는 테마 전환
   - **카테고리별 컬러 & 이모지**: 시각적으로 구분되는 지출 내역

2. **💡 맞춤형 절약 조언 엔진 (`advisor.py`)**
   - **소비 패턴 자동 분석**: 특정 카테고리 과소비 감지, 전월 대비 지출 증가율 분석
   - **라테 효과 감지**: 고빈도 소액 지출(카페, 편의점 등) 분석 및 절약 가능 금액 제안
   - **주말 vs 평일 소비 패턴**: 요일별 평균 지출 분석
   - **예산 초과 경고 및 하루 권장 지출액 계산**

3. **🎯 목표 및 예산 관리**
   - 월별 총 예산 및 카테고리별 세부 예산 설정
   - 실시간 달성률(%) 프로그레스 바 및 잔여 예산 표시

4. **📊 인터랙티브 통계 & 차트 (Chart.js)**
   - 카테고리별 지출 비율 도넛 차트
   - 일별 지출 추이 꺾은선 그래프

5. **⚡ 심플한 아키텍처 (SQLite + Flask)**
   - 복잡한 클라우드나 외부 API 설정 없이 로컬에서 바로 실행
   - `sqlite3`를 사용하여 가볍고 안정적인 데이터 보관

## 📁 프로젝트 구조

```
smart-budget/
├── app.py              # Flask 웹 애플리케이션 진입점 & REST API
├── models.py           # SQLite DB 모델 및 CRUD 함수
├── advisor.py          # 소비 데이터 분석 및 절약 조언 엔진
├── requirements.txt    # Python 패키지 의존성 (flask)
├── static/
│   ├── css/
│   │   └── style.css   # Pretendard 폰트 기반 모던 반응형 스타일시트
│   └── js/
│       └── app.js      # 프론트엔드 비동기 API 통신, 차트, 테마 관리
├── templates/
│   ├── base.html       # 공통 레이아웃 (사이드바 / 모바일 하단바)
│   ├── dashboard.html  # 메인 대시보드 (차트, 통계 요약, 절약 팁)
│   ├── add.html        # 지출/수입 등록 폼 (빠른 금액 버튼, 카테고리 피커)
│   ├── history.html    # 거래 내역 필터링, 수정 모달, 삭제
│   ├── goals.html      # 예산 목표 설정 및 진행률 현황
│   └── advice.html     # 상세 절약 분석 리포트 & 실천 가이드
└── test_app.py         # 자동화 테스트 스위트
```

---

## 🚀 빠른 시작 가이드

### 1. 패키지 설치
```bash
cd smart-budget
pip install -r requirements.txt
```

### 2. 서버 실행
```bash
python app.py
```

실행 후 브라우저에서 아래 주소로 접속합니다:
👉 **`http://localhost:5000`** (또는 로컬 네트워크 `http://127.0.0.1:5000`)

## 📖 주요 페이지 안내

- **대시보드 (`/`)**: 이번 달 총 수입/지출/잔액, 카테고리별 지출 도넛 차트, 일별 지출 추이 그래프, 오늘의 절약 팁 확인
- **입력 (`/add`)**: 5천원, 1만원 등 빠른 금액 선택 버튼과 직관적인 이모지 카테고리 피커로 빠른 지출/수입 등록
- **내역 (`/history`)**: 월별, 카테고리별, 유형(지출/수입)별 필터링 조회 및 내역 수정/삭제
- **목표 (`/goals`)**: 이번 달 전체 예산 및 식비/카페 등 카테고리별 예산 설정과 소진율 확인
- **조언 (`/advice`)**: 분석 엔진이 도출한 소비 습관 문제점 및 절약 실천 가이드 리포트
